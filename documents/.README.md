
# Documents

Esta carpeta contiene la documentación relacionada con el proyecto PROTUD.

Aquí se almacenarán documentos que permitan registrar y explicar el desarrollo del proyecto, incluyendo la descripción del sistema, objetivos, funcionamiento, avances, investigaciones, diagramas, especificaciones y documentación técnica.

El objetivo es mantener organizada toda la información necesaria para comprender el proyecto y facilitar su seguimiento durante las diferentes etapas de desarrollo.
