
# Hardware

Esta carpeta contiene la información relacionada con la estructura física y los componentes electrónicos del robot PROTUD.

Aquí se documentarán los componentes utilizados en el prototipo, conexiones, circuitos, diagramas, planos, diseños del chasis y demás elementos necesarios para la construcción del robot.

El proyecto se encuentra actualmente en una etapa de prototipo, utilizando materiales y componentes disponibles para experimentar, realizar pruebas y validar el funcionamiento de la plataforma.

Esta sección se actualizará a medida que el hardware evolucione hacia versiones más completas del robot.
