
# Media

Esta carpeta contiene el material multimedia relacionado con el desarrollo del proyecto PROTUD.

Aquí se almacenarán fotografías, videos, imágenes del prototipo, capturas de pruebas, registros del proceso de construcción y otros recursos visuales que permitan mostrar la evolución del proyecto.

El objetivo es conservar un registro visual del desarrollo de PROTUD, desde las primeras etapas de construcción hasta las futuras versiones y mejoras del robot.
